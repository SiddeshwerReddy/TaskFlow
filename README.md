# TaskFlow

TaskFlow is a Distributed Job Processing & Workflow Platform. It handles asynchronous background tasks, scheduled jobs, and complex workflows reliably using a distributed architecture.

## Overview
This project is built using:
- Frontend: React, Vite, JavaScript, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose
- Queue: Redis, BullMQ
- Real-time: Socket.io

Please refer to the `docs/` directory for detailed architecture, API, and database designs.
